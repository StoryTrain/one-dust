# One Dust brand assets

Official visual assets for One Dust (1DUST).

This directory provides the project logo in vector and raster formats
for project identification, editorial references, and preparation of
exchange, aggregator, wallet, and other platform submissions.

## Project identity

- Project name: One Dust
- Token ticker: 1DUST
- Primary brand color: `#009595`
- Logo artwork: the original One Dust emblem, with its proportions,
  colors, and internal white elements preserved.

## Logo files

| File | Format / dimensions | Intended use |
|---|---|---|
| [one-dust-logo.svg](one-dust-logo.svg) | SVG, vector | Scalable source artwork |
| [one-dust-logo-256.png](one-dust-logo-256.png) | PNG, 256 × 256 px | Compact token icons and platform submissions |
| [one-dust-logo-512.png](one-dust-logo-512.png) | PNG, 512 × 512 px | General-purpose icons and profile images |
| [one-dust-logo-1024.png](one-dust-logo-1024.png) | PNG, 1024 × 1024 px | High-resolution digital use |
| [one-dust-logo-2000.png](one-dust-logo-2000.png) | PNG, 2000 × 2000 px | Large raster artwork and further exports |
| [one-dust-logo-4000.png](one-dust-logo-4000.png) | PNG, 4000 × 4000 px | High-resolution raster source |
| [one-dust-logo-white-bg-512.png](one-dust-logo-white-bg-512.png) | PNG, 512 × 512 px | Use where a white square background is preferred |

For transparent-background exports, only the area outside the circular
emblem should be transparent. White elements inside the emblem must
remain white.

Platform requirements vary. Check the receiving platform's current
requirements before submitting an asset. Inclusion in this directory
does not mean that a file has been accepted by any platform.

## Usage guidelines

When using the One Dust logo:

- Preserve the original proportions and orientation.
- Keep the original colors and internal white elements.
- Leave enough space around the emblem to avoid clipping.
- Do not stretch, distort, crop, recolor, or redraw the emblem.
- Do not add elements inside the emblem or merge it with another logo.
- Do not use the assets to imply an official partnership, endorsement,
  listing, certification, or security audit that has not been confirmed
  by the One Dust team.
- Do not use the assets to impersonate the project or its team.
